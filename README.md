<h1 align="center">MarkersPlus</h1>

<p align="center">Tactical map symbols, contact reports and saved plans for Arma 3.</p>

<p align="center">
  <a href="https://steamcommunity.com/sharedfiles/filedetails/?id=3364990415"><strong>Steam Workshop</strong></a>
  &nbsp;·&nbsp;
  <a href="https://steamcommunity.com/sharedfiles/filedetails/?id=3365010538"><strong>User guide</strong></a>
  &nbsp;·&nbsp;
  <a href="https://github.com/Pekururu/Markersplus/issues">Issues and suggestions</a>
</p>

- **Markers:** 50 symbols, a searchable icon grid, favorites and quick editing.
- **Contact reports:** record identification, unit type, counts, activity and notes.
- **Saved plans:** save markers, reports, lines and areas for reuse on the same terrain.

Subscribe on the Workshop and enable **CBA_A3 and ACE3** alongside the mod. The [Steam guide](https://steamcommunity.com/sharedfiles/filedetails/?id=3365010538) covers the tools and explains each symbol.

Open the map and use the pin button for markers or the crosshair for contact reports. **Ctrl+Shift+M** opens the marker panel. Reports, the contact list and saved plans are also available through **M+** in ACE self-interaction.

Change preferences under **Addon Options → MarkersPlus** and shortcuts under **Controls → Configure Addons → MarkersPlus**. Hover **Controls** in a panel for your current bindings and mouse gestures.

For full shared contact reports in multiplayer, install MarkersPlus on the server and clients.

Found a problem or have a suggestion? [Open an issue](https://github.com/Pekururu/Markersplus/issues).
